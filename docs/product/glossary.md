# Glossary

| Term | Meaning |
|---|---|
| Allocation | A record that places one tenant in one room for a time range. |
| Attempt | A payment checkout or confirmation process before final payment. |
| Billing frequency | How often a tenant is billed. |
| Bulk import | Spreadsheet-based creation of many tenants. |
| Collection | Money received from tenants. |
| Due | Money a tenant still owes. |
| Grace days | Days after due date before late fee rules apply. |
| Hostel | A property managed by an owner. |
| Invoice | Payment request evidence, often tied to a provider attempt. |
| Ledger | Ordered record of financial changes. |
| Move-out | Tenant exit workflow from request to completion. |
| Obligation | The source-of-truth record for money owed. |
| Owner | User who manages hostels and tenants. |
| Payment | Confirmed money collected from a tenant. |
| Profile | Login identity and personal details for a user. |
| Reconciliation | Process that compares local payment records with provider evidence. |
| Reminder | Notification sent about rent, activation, or operations. |
| Room | Physical rentable space inside a hostel. |
| Settlement | Final money calculation during move-out or owner payout. |
| Tenant | Person staying in a hostel. |

**How this works:**
1. Domain terms map to database models.
2. UI labels simplify these terms for users.
3. Services enforce the exact business meaning.
