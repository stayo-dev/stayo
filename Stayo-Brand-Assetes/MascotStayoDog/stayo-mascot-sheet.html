BRAND CHARACTER — GOLDEN RETRIEVER COMPANION

Meet the Stayo dog

Built in the same rounded, geometric language as the "S" mark — flat shapes, no outlines, six-colour palette only — so it can sit next to the logo without looking like a separate brand. Six emotion states below, each exported as its own SVG with named layers, ready to be rigged for motion.

Why this works for Stayo specifically: a golden retriever's fur sits almost exactly inside your existing Warm Clay / Terra Cotta / Dusty Orange range — nothing was recoloured to force the fit. The temperament fits too: a golden retriever reads as loyal, unthreatening, and eager to help, which is the same "responsible partner" feeling the Launch Kit is built around, just carried onto screen.
Emotion set — v1

Six states, one character

Same head size, body silhouette and proportions throughout — only ears, brows, eyes, mouth, tail and paws change. That consistency is what will make the later animation read as one character moving, not six different drawings.

Built for motion

How this is structured for animation later

Every SVG uses the same named groups, so a single Lottie or GSAP rig can drive all six states without redrawing anything.

  • #ear-left / #ear-right — independent flap/perk rotation
  • #eye-left / #eye-right — swap between dot, arc, and closed shapes for blinking
  • #eyebrow-left / #eyebrow-right — raise for surprise or curiosity
  • #mouth — smile / open-pant / big-open, swappable independent of the eyes
  • #tail — three positions (down, mid, high) built to interpolate as a wag loop
  • #paws — down / one-raised / both-raised, drawn in front of the head group so a raised paw is never clipped
  • #head-group — wraps the whole head as one transform target, already used for the thinking tilt

Suggested first animations to build

Idle loop (2–3s): tail sways between down and mid, one slow blink — keeps the neutral pose from feeling static without demanding attention.

Tail wag (0.4s loop): interpolate the three tail shapes on a sine ease for happy/celebrating states.

Blink (120ms): swap eye-open → eye-closed → eye-open on a random 4–8s interval for any resting state.

Wave-in (0.6s, one-shot): raise the wave paw from the down position on entry to onboarding, then hold.
